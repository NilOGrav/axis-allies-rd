- tests/

are licensed under the MIT License. See the repository-root LICENSE file.

This includes the Python tooling used to process the research data and
generate Graphviz/tree output.

## 2. Original research and design data

Original research/design data is licensed under CC BY 4.0, unless a file
or directory explicitly states otherwise.

This includes original project data such as:

- technology definitions;
- technology dependencies and relationships;
- domains and paths;
- facilities and Research Centres;
- resources and resource territories;
- design principles;
- rules and other original game-system design data.

The primary structured research data is maintained under data/research/.
Both source spreadsheets and exported CSV representations may contain this
original project material.

See LICENSE-DATA.

Where a file contains both original project material and third-party material,
the third-party material is excluded from the project licenses unless the
applicable rights explicitly permit otherwise.

When the licensing status of a particular file is unclear, do not assume that
the project's MIT or CC BY 4.0 license grants additional rights.

provide appropriate attribution to NilOGrav, identify the CC BY 4.0 license,
and indicate if changes were made, as required by that license.
